Privacy by Default, Smarter by Design

Traditional AI utilities compromise privacy and run slow off-grid. Pern turns your device into an independent AI powerhouse.

The Cloud AI Problem

  • Data Exploitation: Every prompt, document, and private message is sent to external data centers.
  • Fragile Connectivity: Standard assistants break entirely when you go offline or have weak coverage.
  • Static Context: Model knowledge stays general, lacking context about your local tools or routines.

How Pern Solves It

  • Absolute Privacy: Zero cloud servers. Local LLMs handle reasoning natively inside your hardware boundaries.
  • True Offline Autonomy: Fully operational off-grid. Run completions, process text files, and moderate bots.
  • Skills Learner & Memory: Learns habits and logs actions to a local memory file, making the AI smarter contextually.

Features Designed for Power Users

Pern binds local LLMs directly with your workspace tools securely and efficiently.

Local Llama Server

Launches a native llama-server instance using GGUF chat models. Fully supports streamed completions and instant cancellation.

Deep Tool Ecosystem

Natively link and automate operations on WhatsApp, Discord bot runners, local system terminals, email clients, and file workspaces.

On-Device Memory

An on-device learning engine. Tracks tool usage statistics to optimize workflows and logs long-term memories locally.

Multi-Platform UI

Tauri-powered lightweight UI. Tailored configurations for Windows (system tray attachment) and Android viewports.

How It Works

Get up and running with a complete local LLM execution pipeline in three steps.

01

One-Click Onboarding

On first run, Pern verifies your hardware architecture, downloads the correct platform-specific llama-server binary, and configures local runtime folders automatically.

Auto-Detect CPU/GPU Zero Dependencies Needed
02

Model Registry Selection

Select from a library of highly optimized GGUF chat and reasoning models matching your computer RAM. Pern fetches them directly from Hugging Face to your local disk.

Gemma 4 Qwen 2.5 DeepSeek R1 Distill
03

Authorize Integrations

Enable connections as needed: QR-scan for WhatsApp, paste bot tokens for Discord moderation, setup SMTP/IMAP configurations for email, or link local code folders.
